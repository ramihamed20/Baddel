# بدّل — Baddel

موقع عربي بسيط لتبادل شعب وقروبات الطلبة، مستضاف بالكامل على **GitHub Pages** بدون VPS أو خادم Python أو قاعدة SQLite.

## كيف يشتغل؟

- الشعب: A و B؛ وفي كل شعبة القروبات A1 و A2 و B1 و B2 و C1 و C2 و D1 و D2.
- عرض طلبات التبديل العامة والبحث حسب الشعبة والقروب الحالي والمطلوب.
- كشف التطابق العكسي: طلب A-C1 → B-A2 يتطابق مع B-A2 → A-C1.
- التواصل بين الطلبة عبر روابط Telegram.

### أين تُخزّن الطلبات؟

نستخدم **GitHub Issues** في هذا المستودع كمصدر مشترك للطلبات؛ الموقع يقرأ الـ Issues العامة بواسطة GitHub API.

**شرط مهم:** قراءة الطلبات متاحة للجميع، لكن نشر طلب يحتاج تسجيل الدخول إلى **حساب GitHub** ثم الضغط على **Submit new issue** لتأكيد نشره. هذا شرط لا يمكن إلغاؤه مع حل GitHub-only بدون خادم. يختفي الطلب من واجهة الموقع بعد 30 يومًا أو فور إغلاق الـ Issue؛ قد يظل نص الطلب متاحًا في سجل GitHub العام حتى بعد إغلاقه. لا تنشر رقم هاتفك أو أي بيانات خاصة؛ اسم مستخدم Telegram نفسه سيكون عامًا.

قد تفرض واجهة GitHub API حدودًا مؤقتة لعدد مرات القراءة، وقد يتأخر ظهور الطلب الجديد للحظات بسبب التخزين المؤقت.

## نشر الموقع عبر GitHub Pages

1. افتح [Settings → Pages](https://github.com/ramihamed20/Baddel/settings/pages) في هذا المستودع.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. بعد اكتمال النشر افتح: **https://ramihamed20.github.io/Baddel/**.

تأكد كذلك أن ميزة **Issues** مفعلة في Settings → General → Features.

## الملفات المطلوبة للموقع

- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — قراءة الطلبات والمطابقة والبحث ونموذج النشر.
- `favicon.svg` — أيقونة الموقع.
- `.nojekyll` — توجيه GitHub Pages لنشر الملفات كما هي.

لا تحتاج إلى Docker أو Python أو مفاتيح API أو أسرار توضع داخل الواجهة.

## التشغيل محليًا

شغّل أي خادم ملفات ثابتة من المجلد (ليس هناك خادم خلفي):

```bash
python3 -m http.server 8000
```

ثم افتح http://127.0.0.1:8000/ . الاتصال بالإنترنت مطلوب لتحميل الطلبات من GitHub.

## تنبيه حول نشر الطلبات

الضغط على «أكمل نشر الطلب على GitHub» **لا يعني أن الطلب نُشر فورًا**. ستنتقل إلى GitHub، وإذا لم تكن مسجّلًا الدخول ستُطلب منك المصادقة، ثم تراجع الطلب وتضغط **Submit new issue**. بعد تأكيد النشر، اضغط «تحديث الطلبات» في الموقع. لإخفاء الطلب، أغلق الـ Issue من GitHub.
