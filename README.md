# بدّل — موقع لتبادل قروبات الطلبة

موقع عربي خفيف ومستقل (RTL)، ينشر فيه الطالب طلب انتقال من شعبة/قروب إلى شعبة/قروب، ويبحث عن طلبات الطلبة الآخرين ويتواصل معهم عبر تيليجرام. لا يتطلب إنشاء حساب.

## القروبات والوظائف

- شعبتان: **A** و **B**، وفي كل شعبة 8 قروبات: `A1 A2 B1 B2 C1 C2 D1 D2`.
- الانتقال داخل الشعبة أو بين الشعبتين (مثل `A-C1 → A-A2` أو `B-A1 → A-C2`).
- صفحة عامة بها أحدث الطلبات مع بحث مستقل في «من» و«إلى» (شعبة وقروب) وزر لعكس اتجاه البحث.
- نشر الطلب بيوزر تيليجرام، ثم البحث آليًا عن الطلبات **المعاكسة بالضبط**، مع روابط مباشرة للتواصل.
- «طلباتي» وحذف طلباتك من **نفس المتصفح**؛ يتم الاحتفاظ بمفتاح الحذف محليًا، ولا يُظهر الخادم هذا المفتاح للزوار.
- إحصاء الطلبات وفرص المطابقة؛ تنتهي صلاحية الطلبات تلقائيًا بعد 30 يومًا.
- قاعدة SQLite مشتركة بين كل الزوار وتبقى محفوظة بعد إعادة تشغيل السيرفر؛ ليست مجرد حفظ في المتصفح.

**مثال:** طلب 1: `A-C1 → A-A2`، وطلب 2: `A-A2 → A-C1` ⇒ تطابق مباشر. والشيء نفسه يشتغل بين شعبتي A وB.

## التشغيل السريع

المتطلبات: **Python 3.10 أو أحدث** فقط، بدون تثبيت مكتبات:

```bash
cd baddel
python3 server.py
```

افتح `http://127.0.0.1:8787`.

لتغيير العنوان والمنفذ:

```bash
HOST=0.0.0.0 PORT=8787 python3 server.py
```

أو باستخدام Docker:

```bash
docker compose up -d --build
```

ثم افتح `http://localhost:8787` على الجهاز نفسه، أو اضبط reverse proxy (Caddy/Nginx) مع HTTPS والدومين على السيرفر. يربط Docker المنفذ على localhost فقط بصورة افتراضية للحماية؛ يمكنك تغيير الربط في `compose.yaml` عند الحاجة.

## API

| الطريقة | المسار | الوظيفة |
|--|--|--|
| GET | `/api/health` | فحص الجاهزية |
| GET | `/api/stats` | إجمالي الطلبات وفرص التطابق |
| GET | `/api/requests?current_section=A&current_group=C1&target_section=B&target_group=A2` | البحث، وتدعم `limit` و`offset` |
| POST | `/api/requests` | إنشاء طلب |
| GET | `/api/requests/{id}` | عرض طلب |
| GET | `/api/requests/{id}/matches` | إظهار طلبات التبادل العكسي |
| DELETE | `/api/requests/{id}` | حذف الطلب باستخدام هيدر `X-Owner-Token` |

مثال الطلب عند الإنشاء:

```json
{
  "current_section": "A", "current_group": "C1",
  "target_section": "A", "target_group": "A2",
  "telegram": "student_user", "consent": true
}
```

## الخصوصية والتشغيل العام

- اليوزر المنشور **عام** وسيكون رابط `t.me/username` ظاهرًا للزوار. لهذا يطلب التطبيق موافقة واضحة قبل النشر.
- يلزم أن يكون اسم مستخدم تيليجرام 5–32 حرفًا/رقمًا/`_`؛ لا يحتاج رقم هاتف.
- يُخزّن مفتاح الحذف محليًا. مسح بيانات المتصفح أو تغيير الجهاز يعني فقدان قدرة الحذف، لذا استخدم متصفحك المعتاد حتى انتهاء الطلب.
- لا يتحقق التطبيق حاليًا من هوية الطالب أو ملكية حساب تيليجرام؛ لا تشارك بياناتك الشخصية مع شخص مجهول. لا يضمن الموقع موافقة إدارة الجامعة أو تنفيذ النقل.
- لتشغيل إنتاجي عام وازدحام كبير: استخدم HTTPS وreverse proxy بحدود طلبات، ونسخًا احتياطية لقاعدة SQLite (المجلد `data/` محليًا أو Docker volume `baddel-data`)، وراقب قاعدة البيانات. معدل النشر حاليًا 12 طلبًا لكل عنوان IP في الساعة، على مستوى عملية السيرفر (ويُعاد تعيينه عند إعادة التشغيل).
- قاعدة SQLite على حجم استخدام محدود/متوسط مناسبة؛ يمكن الانتقال لاحقًا إلى Postgres إذا لزم.

## الملفات

`server.py` — الخادم وواجهة API وSQLite، `public/` — واجهة HTML/CSS/JS، `compose.yaml` و`Dockerfile` — للتشغيل، `data/` — قاعدة البيانات في التشغيل المحلي (مستبعدة من حزمة التسليم)؛ Docker يحفظها في Volume دائم باسم `baddel-data`.
